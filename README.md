* carmitre_module/, clamav_module/, nmap_module/: Will contain the code of each module
* config: Files with the global config or each module
* docs: Documentation of the proyect
* main: The main script that will orchestrate the execution of the modules
* reports: Folder with all the reports generated of each module
* tests: Testing of the tools and the main 
* utils Functions and auxiliary classes that can be used by multiple modules
